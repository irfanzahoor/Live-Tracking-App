# 📍 Live Tracking App

A Flutter app for live location tracking using Google Maps, Directions API, custom markers, and polylines.

### 🔧 Tools & Packages Used:
- Flutter & Dart
- [google_maps_flutter](https://pub.dev/packages/google_maps_flutter)
- [location](https://pub.dev/packages/location)
- [flutter_polyline_points](https://pub.dev/packages/flutter_polyline_points)

### 🚀 Features:
- Live user location tracking  
- Markers on map  
- Route drawing with polylines  

⚠️ Don't forget to add your **Google Maps API Key** in `AndroidManifest.xml`.
